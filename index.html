Icon Hub Guide: Naye Icons Kaise Add Karein & Kahin Bhi Kaise Use Karein?

1. 🚀 GitHub Par Upload Karna

Apne project ko GitHub repository me push karein. GitHub Pages enable karne ke liye:

  1. GitHub Repo me Settings → Pages me jayein.
  2. Branch me main / master select karke Save karein.

2. 🔄 Naye SVGs Auto-Add Hona

Aane wale samay me jab bhi aap naye .svg files is folder me add karenge:

  • GitHub par commit karte hi GitHub Action automatically icons.json update kar dega!
  • Aap is page par "Auto Sync" button daba kar GitHub se turant live icons fetch kar sakte hain!
  • Offline/Local testing ke liye update-icons.bat par double-click karein.

3. 💻 Projects me Link Use Karna

Kisi bhi website ya app me icon direct lagane ke liye Copy Link ya Copy <img> button dabayein:

<img src="https://cdn.jsdelivr.net/gh/USERNAME/REPO@main/discord1.svg" width="24" height="24" />

jsDelivr CDN sabse best hai kyunki ye ultra-fast hai aur kabhi block nahi hota!
